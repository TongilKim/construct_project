# 건설 도면 지식 검색 (Hybrid GraphRAG)

## 해결하려는 문제

현장 엔지니어는 도면을 보며 "안방 바닥은 뭘로 마감해?", "현관문 프레임 마감이 뭐야?" 같은 질문을 한다. 사람은 평면도에서 방을 찾고, 도어 스케줄과 마감재 리스트를 오가며 답을 맞춘다. 이 일을 시스템이 대신하려면 아래 네 가지를 풀어야 한다.

### 1. 답이 한 장에 없다

도면은 종류마다 담는 정보가 다르다. 평면도(A-001)에는 방의 위치만, 도어 스케줄(A-003)에는 문 사양만, 마감재 리스트(G-103)에는 방 유형별 마감만 있다. "안방 바닥 마감재와 그 방에 다는 문"을 물으면 마감재 리스트와 도어 스케줄을 둘 다 읽어야 한다.

페이지 단위로 잘라 넣은 벡터 검색은 비슷한 페이지를 따로따로 가져올 뿐이다. 평면도의 `ENTRY`, 도어 스케줄의 LOCATION `ENTRY`, 마감재 리스트의 `ENTRY` 행이 같은 공간이라는 연결은 알려 주지 않는다.

모든 도면이 같은 세대를 그린 것도 아니다. 평면도(A-001)는 A타입, 구조 평면도(S-002)는 B타입 세대라서 두 도면의 공간을 그대로 겹칠 수 없다.

### 2. 사용자의 말과 도면의 표기가 다르다

- 사용자는 "안방"이라고 하지만 평면도에는 `MASTER BEDROOM`, 도어 스케줄에는 `MASTER BED ROOM`으로 적혀 있다. 같은 방이 도면마다 다르게 쓰인다.
- "방화문"은 도어 스케줄에 `FSD`라는 태그로만 나온다.
- 마감재 리스트에는 `MASTER BEDROOM` 행이 없다. 침실 행은 `BADROOM`(BEDROOM의 오타로 보임) 하나뿐이다. 안방 바닥 마감을 찾으려면 안방이 이 행에 해당한다고 판단해야 한다.

### 3. 입력이 이미지다

도면은 PNG 이미지다. 한 장 안에 표, 원 안의 태그 심볼(`11X22`, `FSD` 등), 치수선, 범례가 섞여 있다. 표도 도면마다 생김새가 다르다. 도어 스케줄은 문 하나마다 칸이 따로 있고, 보 일람표(S-222)는 보 하나를 위치별 열(INT., CENTER, EXT.)로 나눈다. "G1 보 상부 철근이 위치마다 어떻게 다른가"에 답하려면 G1 아래 INT.(BOTH) 열의 `15-UHD22`와 CENTER 열의 `4-UHD22`를 구분해 읽어야 한다.

### 4. 근거를 보여 줘야 한다

현장에서는 답만으로 일을 진행하지 않는다. 어느 도면의 어느 항목을 거쳐 나온 답인지 확인할 수 있어야 한다. 그래서 검색하면서 거친 도면 번호와 항목을 답과 함께 남겨야 한다.

도면 번호도 그대로 믿기 어렵다. 마감재 리스트는 파일 이름이 G-103인데 표제란의 도면 번호는 G-101이다.

## 답해야 하는 질문 유형

| 질문 | 필요한 도면 | 어려운 점 |
|---|---|---|
| 마스터 베드룸 문의 재질은? | A-003 | 한 장 안에서 답할 수 있음 |
| 현관 문의 프레임 마감은? | A-001, A-003 | 평면도의 공간과 도어 스케줄 LOCATION 연결 |
| 안방 바닥 마감재와 그 방에 다는 문 종류는? | G-103, A-003 | 표기 불일치, 도면 두 장을 이어 읽기 |
| G1 보 상부 철근은 위치에 따라 어떻게 다른가? | S-222 | 일람표의 열 구조 해석 |

## 입력 도면

`drawings/` 폴더의 건축·구조 도면 6장이다.

| 파일 | 도면 번호 | 내용 |
|---|---|---|
| `01_G-103_finishing_material_list.png` | G-103 (표제란 G-101) | 실별 마감재 리스트. 공간별 바닥, 걸레받이, 벽, 천장 마감 |
| `02_G-102_finishing_material_detail.png` | G-102 | 마감 상세. 마감 코드(F01, B01 등)별 단면 |
| `03_A-001_unit_floor_plan_A_type.png` | A-001 | A타입 세대 평면도. 공간 배치 |
| `04_A-003_door_schedule.png` | A-003 | 도어 스케줄. 도어 태그, 설치 위치, 프레임과 문 마감 |
| `05_S-002_structural_floor_plan_B_type.png` | S-002 | B타입 구조 평면도. 벽체 태그(W1, WB1, CW1 등) |
| `06_S-222_beam_schedule.png` | S-222 | 지하주차장 보 일람표. 보 타입(G1, G11 등)별 단면과 배근 |
